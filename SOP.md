# Standard Operating Procedure (SOP): Autonomous Storyboard Generation & Curation Pipeline

## 1. Objective
To autonomously generate, evaluate, and curate **334 production-ready storyboard images** for the video script using **Google Flow (Nano Banana 2 model, 16:9 widescreen, 2 variations per prompt, 0 credits)**, ensuring full-bleed composition, consistent ink explainer visual language, and zero manual intervention under strict fault-tolerant safety rules.

---

## 2. Model & Batch Configuration (Updated)
- **Primary Model**: `🍌 Nano Banana 2` (0 credits, fast & reliable)
- **Model Cascade Chain**: `Nano Banana 2` → `Nano Banana Pro` → `Nano Banana 2 Lite`
- **Variations per Prompt**: `x2` (reduced from 4 to 2 to optimize generation speed and prevent rate-limiting)
- **Aspect Ratio**: `16:9` widescreen (1376 × 768 native render)
- **Credit Cost**: `0 Credits`
- **Pacing Interval**: `10 to 30 seconds` random delay between completed generations

---

## 4. Step-by-Step Execution Protocol (Per Prompt)

For each Shot $N$ from 1 to 334:

### Step 1: Pre-Execution Verification
- Check if `Final selected images/shot_{N:03d}.jpg` already exists.
- If it exists, mark status as `[COMPLETED]`, skip generation, and immediately advance to Shot $N+1$.

### Step 2: Prompt Submission in Google Flow
- Focus the `.ProseMirror` editor on the active Google Flow project tab via Chrome CDP (port 9222).
- Inject the exact full-bleed prompt for Shot $N$.
- Verify model configuration is set to active model in cascade (`Nano Banana 2` / `Pro` / `2 Lite`) and `x2` variations.
- Click `Start generation` (`button[aria-label="Start generation"]`).

### Step 3: Render Monitoring, Partial Ingestion & Failsafe Cascade
- Continuously poll the DOM every 2.5 seconds (up to 50 seconds max wait).
- **Error Trigger Check**: Scan DOM for error banners, toasts, or text matching:
  - `"failed generation"`, `"something went wrong"`, `"unusual activity"`, `"generation failed"`, `"try again later"`, `"reached your usage limit"`.
- **Partial Generation Usability Check (1-Image Rule)**:
  - If a full batch (2 variations) did not complete or an error occurred, BUT at least 1 image was rendered (`len(new_srcs) >= 1`):
    - Download and evaluate that single image using computer vision scoring.
    - If `score >= 50.0` (usable): Accept it immediately as the final image for Shot $N$, save to final folders, reset failure counters, and advance to Step 5!
    - If `score < 50.0` (unusable): Reject the image and proceed to failure cooldown.
- **Escalating Failure Intervals & Model Cascade**:
  1. **Failure #1 on Shot $N$**:
     - Reload page (`flow_page.reload()`).
     - Wait **3 minutes (180 seconds)** cooldown.
     - Retry Shot $N$ with current model.
  2. **Failure #2 on Shot $N$**:
     - Reload page (`flow_page.reload()`).
     - Wait **5 minutes (300 seconds)** cooldown.
     - Retry Shot $N$ with current model.
  3. **Failure #3 on Shot $N$**:
     - Do NOT halt yet!
     - Shift model to the next model in cascade: `Nano Banana 2` → `Nano Banana Pro` → `Nano Banana 2 Lite`.
     - Reset consecutive failure counter to 0 for the new model.
     - Wait 30 seconds for UI stabilization, re-verify `x2` setting, and retry Shot $N$.
  4. **Exhaustion Halt**:
     - If all models in the cascade fail 3 times on the same shot:
       - Save full-page error screenshot (`2- Code/flow_error_halt.png`).
       - Update `production_status.json` with status `"HALTED_CONSECUTIVE_FAILURES"`.
       - **HALT PIPELINE and prompt the user.**

### Step 4: Asset Ingestion & Multi-Metric Computer Vision Scoring
- Once image variations render successfully:
  - Reset `consecutive_failures = 0`.
  - Download variations at native 1376×768 resolution to `3- Finals/flow_generated_images/shot_{N:03d}_var_{1..2}.jpg`.
  - Run multi-metric image evaluation:
    1. **Sharpness & Line Art Clarity (30% weight)**: Laplacian edge variance scoring crisp black ink contours.
    2. **Subject Prominence & Center Focus (25% weight)**: Contrast distribution focusing on primary subject.
    3. **Tonal Dynamic Range (25% weight)**: Percentile value distribution ensuring ink depth without blown highlights.
    4. **Information Entropy (20% weight)**: Detail density and narrative clarity.
    5. **Full-Bleed Penalty**: Automatic -50 point penalty if solid white card border/matting is detected.

### Step 5: Final Selection, Archival, Pacing & Status Tagging
- Identify the highest-scoring variation.
- Copy winning variation to:
  - `Final selected images/shot_{N:03d}.jpg`
  - `3- Finals/Final selected images/shot_{N:03d}.jpg`
- Append record to `3- Finals/selection_log.csv`.
- Update `[STATUS: COMPLETED]` in `3- Finals/all_prompts.txt`.
- Update progress metrics in `PROMPT_STATUS.md` and `production_status.json`.
- **Random Pacing Delay**: Wait a randomized interval between **10 and 30 seconds** before beginning the next prompt to maintain natural traffic patterns.
- Advance to Shot $N+1$.

---

## 5. Quality Standard
- **Resolution**: 1376 × 768 native 16:9 widescreen.
- **Style Consistency**: Minimalist 2D vector comic linework, bold black ink outlines, flat muted colors, edge-to-edge environment grounding.
- **Zero Border Policy**: 100% full bleed. No floating cards, no white matting borders.
