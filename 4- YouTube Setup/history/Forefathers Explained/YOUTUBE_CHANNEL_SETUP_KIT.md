## ⚙️ 4. Channel Settings & Optimization (YouTube Studio > Settings)

### A. Channel > Advanced Settings
* **Audience**: Select **"No, set this channel as not made for kids. I never upload content that's made for kids."**  
  *(Essential: Selecting this enables comments, community posts, notification bells, and monetization).*
* **Google Ads account linking**: Leave unlinked initially.
* **Automatic captions**: Check **"Don't show potentially inappropriate words"**.
* **Clips**: Check **"Allow viewers to clip my content"** (Free organic reach).

### B. Channel > Feature Eligibility
* **Standard features**: Enabled by default (video uploads, playlist creation).
* **Intermediate features**: Click **Verify Phone Number** (Enables videos longer than 15 minutes, custom thumbnails, and live streaming).

### C. Upload Defaults > Basic Info
* **Visibility**: Set default to `Unlisted` *(Always upload as unlisted first so 1080p/4K processing and copyright checks finish before going public!)*.
